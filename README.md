# career-consultant-skill

Карьерный консультант для Claude Code: честная оценка достижимости цели, резюме, отбор вакансий, подготовка к собеседованию, торг за оффер. Любая профессия и уровень. Рынок по умолчанию — Россия и СНГ, методика универсальная.

*A career-consultant skill for Claude Code: feasibility check first, then resume, vacancy scoring, interview prep and salary negotiation. Russian market layer is a separate, swappable file; the methodology is market-agnostic. Docs are in Russian.*

---

## Чем отличается от «помоги с резюме»

Обычный карьерный ИИ берёт цель человека как данность и начинает полировать резюме. Этот скилл сначала проверяет, возьмут ли туда вообще.

- **Достижимость цели проверяется до всего остального.** Реальные вакансии, шесть осей оценки, ворота по формальным отсечкам, вердикт: проходной / пограничный / не возьмут сейчас. Если не возьмут — что закрыть, за какой срок и через какую промежуточную должность.
- **Вакансия получает не один балл, а балл и два разреза.** Балл 1–5 отвечает «стоит ли тратить время» и режется кэпами: ворота, красная линия, скачок ступени, токсичный текст. Рядом — проходимость («возьмут ли») и пригодность («надо ли тебе туда»), без кэпов: «4.3 / 1.8» говорит, что вакансия под тебя, но тебе туда не надо, а усреднённый балл это стирает. Причина кэпа — рядом, словами.
- **Интервью о потребности идёт до оценки.** От чего человек уходит (потолок, люди, содержание, условия — это четыре разных маршрута), что важно и в каком порядке, красные линии. Для тех, кто не знает, чего хочет, — глубокий режим по протоколу Савикаса.
- **Не поддакивает.** Одна ручка «прямота 1–5» меняет только формулировки; оценки, разрывы и причины одинаковы на всех уровнях. Попросить «помягче» и получить более лестный вывод нельзя.
- **Не приписывает опыт.** Сквозной модуль честности: границу «переформулировать / выдумать» проверяет на каждой правке. Попросишь написать навык, которого нет, — откажет и даст рабочую альтернативу.
- **Не выдумывает цифры.** Зарплаты и требования берутся из реальных вакансий. Нет данных — говорит, что нет.
- **Не отправляет ничего сам.** Готовит отклик, письмо, ответ — нажимает человек.
- **Рынок — отдельным файлом.** Вся методика работает на любом рынке; факты о России (роботы-отсевщики hh, НДФЛ, формы оформления, площадки) лежат в одном `market-ru.md`. Сменить страну — подменить один файл.

## Что умеет

| Скажи ему | Что получишь |
|---|---|
| «что-то не так, не знаю что» | Интервью о потребности: триггер ухода, приоритеты, красные линии, ресурс |
| «дорасту ли я до…» | Вердикт по достижимости с обоснованием по реальным вакансиям и маршрут, если сейчас не возьмут |
| «посмотри резюме» | Разбор по 8 направлениям, переписанные формулировки |
| «напиши резюме» | Готовый текст, а не советы |
| «переделай под эту вакансию» | Адаптация без приписывания того, чего нет |
| вакансия + «стоит ли откликаться» | Балл 1–5 с порогом, рядом проходимость и пригодность без кэпов, причина кэпа словами, отдельно — настоящая ли вакансия |
| «сопроводительное» | Письмо с зацепкой из текста именно этой вакансии |
| «завтра собеседование» | Прогноз вопросов, репетиция, разбор ответов по 5 осям |
| «как прошло» | Где именно потерял и почему |
| «сколько просить», «дали оффер» | Вилка по реальным данным, переговорная позиция, готовые фразы |

Между сессиями ведёт досье: цель, вердикт, факты с пометкой источника, банк историй, журнал откликов, что уже пробовали. Несколько клиентов — несколько папок.

## Установка

**Вариант 1 — как плагин** (одной командой, обновляется через `claude plugin update`):

```bash
claude plugin marketplace add lezg1n89/career-consultant-skill
claude plugin install career@career-consultant-skill
```

**Вариант 2 — копированием** (работает в Claude Code, Codex, Cursor и других агентах, понимающих формат skills):

```bash
git clone https://github.com/lezg1n89/career-consultant-skill.git
cp -r career-consultant-skill/skills/career ~/.claude/skills/career
```

Проверка: в новой сессии напиши `/career` — должен спросить, что происходит.

## Как пользоваться

Подробно — в [USAGE.md](USAGE.md). Коротко: ничего вызывать не нужно, он включается сам, когда речь о резюме, вакансиях, собеседованиях или деньгах. Явный вызов — `/career`.

Первый разговор: четыре стартовых вопроса → интервью о потребности → проверка достижимости → только потом резюме. Порядок не случайный: полировать резюме под должность, на которую не берут или с которой уйдёшь через полгода, — потраченные месяцы.

Жёсткость: «поставь прямоту 4». На уровне 5 включается разбор на прочность — слепые зоны, взгляд скептика, одна неудобная правда без смягчения.

## Как устроено

```
skills/career/
├── SKILL.md                 характер, железные правила, роутер по задачам
└── references/
    ├── intake.md            интервью о потребности, глубокий режим по Савикасу
    ├── feasibility.md       достижимость цели: оси, ворота, вердикт, маршрут
    ├── resume.md            ревизия, сборка с нуля, адаптация под вакансию
    ├── truthfulness.md      сквозной слой: переформулировать можно, выдумывать нельзя
    ├── apply.md             разбор вакансии, балл + два разреза, кэпы, реальность, отклик, письмо, журнал
    ├── stories.md           банк историй под вопросы интервью
    ├── interview.md         подготовка, репетиция, разбор, рубрика по 5 осям
    ├── salary.md            вилка по данным, три числа, торг, манипуляции рекрутёра
    ├── challenge.md         разбор на прочность (только прямота 5)
    ├── dossier.md           схема досье, пороги обобщения, приватность
    └── market-ru.md         ФАКТЫ о российском рынке — единственный рыночный файл
```

Принцип: **методика отдельно, рынок отдельно.** Ни один модуль методики не содержит рыночных фактов — только ссылки на `market-ru.md`. Это не эстетика: в одном из проектов-источников русская локализация была сделана форком и за год отстала от основной ветки вчетверо, потому что переводили со старого среза.

### Другой рынок

Написать `market-xx.md` по той же структуре (10 разделов: отсев, площадки, форма резюме, налоги, формы оформления, бенефиты, нормы найма, воронка, источники данных, что перепроверять), заменить ссылки в `SKILL.md` — и всё. Методику не трогать.

## Что в рыночном файле, чего многие не знают

Между откликом на hh и живым рекрутёром стоит до трёх роботов, и читают они **разное**:

1. **Авторазбор hh** — только анкета (образование, языки, город, опыт, зарплатные ожидания). Текст не читает. Пустое поле не пропускает, а подвешивает отклик. Отказ за 15 минут — это он.
2. **Система работодателя** (Talantix, Хантфлоу, Поток, Skillaz) — наоборот, читает текст, но не понимает синонимов, не читает таблицы и не открывает ссылки.
3. **Робот вместо первого собеседования** — голосовой или видео.

Отсюда практика: анкета заполнена полностью, термины — из текста вакансии, всё существенное — текстом в резюме, а не по ссылке. Набивка ключевыми словами больше не работает: системы учатся её отсеивать.

## Ограничения — честно

- **Публичный API hh закрыт для соискателей** с декабря 2025. Вакансии собираются через веб-поиск и то, что даёт сам человек. Автоматического сканирования hh нет и не будет.
- **Автооткликов нет и не будет.** Они запрещены правилами hh, за них ограничивают аккаунт, и это ломает принцип «готовлю я, нажимаешь ты».
- **Рыночные факты датированы** (дата в шапке `market-ru.md`). Там же список, что и когда перепроверять: налоги — в январе, механику hh — раз в полгода.
- Скилл — это текст методики, а не приложение. Качество работы зависит от модели, которая его исполняет.

## Источники

Методика собрана из трёх открытых проектов (разобраны, переписаны своими словами, отфильтрованы от американской специфики — ATS-вендоров, LinkedIn, Glassdoor, опционов) и профессиональных подходов к карьерному консультированию:

- [noamseg/interview-coach-skill](https://github.com/noamseg/interview-coach-skill) (MIT) — разделение тона и диагноза, протокол оспаривания, рубрика оценки ответа, схема памяти
- [santifer/career-ops](https://github.com/santifer/career-ops) (MIT) — балл вакансии с порогом, признаки нереальной вакансии, границы автономии, урок про локализацию
- [Zal4DW/career-helper](https://github.com/Zal4DW/career-helper) — маршрутизация по ситуации, защита от выдуманных фактов
- [donslice/claude-career-coach](https://github.com/donslice/claude-career-coach) — провокация «за что согласился бы на меньшие деньги» и принудительное ранжирование
- [JacobLinCool/ux-discovery-interviewer-skill](https://github.com/JacobLinCool/ux-discovery-interviewer-skill) — протокол раундов интервью
- Mark Savickas, Career Construction Interview — семь вопросов глубокого режима
- Исследования сикофансии и persona collapse в LLM-советниках — то, почему «прямота» отделена от «диагноза»

Модуль достижимости цели, модуль честности, интервью о потребности и рыночный слой написаны с нуля — в источниках этого не было.
